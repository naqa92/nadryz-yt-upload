Règles de confidentialité

Application « Nadryz YT Upload ». Dernière mise à jour : 2 septembre 2026.

Portée

Nadryz YT Upload est un outil personnel en ligne de commande. Son seul utilisateur est son auteur, Nadir Debaa, qui l'emploie sur sa propre chaîne YouTube. L'application n'a pas de serveur, pas de base de données et pas d'utilisateurs tiers.

Utilisation des Services API YouTube

Cette application utilise les Services API YouTube. En l'utilisant, vous acceptez les Conditions d'utilisation de YouTube. Les données reçues des API YouTube sont traitées conformément aux Règles de confidentialité de Google.

L'usage des informations reçues des API Google par cette application respecte la règle relative aux données utilisateur des services d'API Google, y compris ses exigences d'utilisation limitée.

Données consultées

Après votre consentement Google, l'application accède à votre compte YouTube pour :

  • créer des vidéos et définir leur titre, description, tags, miniature et visibilité (https://www.googleapis.com/auth/youtube.force-ssl) ;
  • lire les statistiques de vos propres vidéos publiées, en lecture seule (https://www.googleapis.com/auth/yt-analytics.readonly).

Aucune donnée de profil, aucun contact et aucune donnée d'une autre application Google n'est consultée. Aucune donnée n'est utilisée pour de la publicité, du profilage ou l'entraînement de modèles.

Stockage et conservation

Le jeton OAuth délivré par Google est enregistré sur la machine locale de l'utilisateur, dans son répertoire personnel, avec des permissions restreintes à ce seul compte système. Il ne quitte jamais cette machine. Aucune donnée n'est transmise ailleurs que vers les API de Google, et rien n'est conservé sur un serveur distant.

Les données lues via les API YouTube ne sont pas stockées de façon persistante : elles sont affichées puis écartées à la fin de l'exécution. Aucune métrique dérivée n'est conservée au-delà des délais prévus par les Règles pour les développeurs YouTube.

Suppression des données

L'accès se révoque à tout moment depuis la page des autorisations de votre compte Google (ou security.google.com). Le jeton local se supprime en effaçant le répertoire de configuration de l'application ; la suppression est immédiate et définitive, aucune copie n'existant ailleurs. Pour toute demande de suppression, écrire à l'adresse ci-dessous : la suppression est effectuée sous 30 jours.

Partage

Aucune donnée n'est vendue, louée ni partagée avec un tiers.
